# Code of Conduct

This project uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Standards

Participants are expected to be respectful, constructive, and focused on improving a local-first learning tool.

Unacceptable behavior includes harassment, discriminatory language, publishing private learning data, publishing API keys, or pressuring users to disclose private study records.

## Enforcement

Maintainers may remove comments, close issues, or restrict participation when behavior harms the project community or user privacy.
