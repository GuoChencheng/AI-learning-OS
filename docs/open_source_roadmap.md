# Open Source Roadmap

## v0.1

Local CLI, YAML/Markdown storage, prompt generation, context packs, event logs, validation, and local Web UI cockpit.

## v0.2

Optional user-provided provider system, explicit connected-mode AI runs, AI run artifacts, provider settings UI, and stronger privacy documentation.

## v0.3

Improved review and test workflows, better due/retrieval scheduling, and smoother UI actions for applying reviewed AI outputs manually.

## v0.4

Plugin-style provider extensions and richer import/export helpers without adding cloud sync or a vector database.

## v0.5

Packaged desktop app while preserving local-first file ownership and prompt-only default mode.
